# Nexus Hackathon Edition
Beginner-friendly Flask + HTML/CSS community finance project.

Features: dashboard, transactions, budgets, budget alerts, What-If simulator, financial health indicator, student money lessons, community-impact page, demo data, report export, local CSV storage.

Run:
py -m venv venv
.\\venv\\Scripts\\python.exe -m pip install -r requirements.txt
.\\venv\\Scripts\\python.exe app.py
Open http://127.0.0.1:5000

Educational project; not financial advice.
